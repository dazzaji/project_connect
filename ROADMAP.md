# Roadmap

## 1. Two-Way Conformance and Interoperability Test

Conduct a two-way test that:

- tests each of two Interlateral Platform implementations for conformance to
  the Interlateral Protocol; and
- tests interoperability between those two implementations according to the
  protocol.

# Possible Future Work

- Three-way interoperability testing in which one participating implementation
  is a continuous test service offered by the federation.
